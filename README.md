# вадян — сайт-приложение (PWA)

Это веб-версия «вадян», которую можно добавить на экран «Домой» iPhone.

## Как пользоваться на iPhone

1. Разместите содержимое этой папки на HTTPS-сайте.
2. Откройте сайт в Safari.
3. Нажмите «Поделиться».
4. Выберите «На экран Домой».
5. Запустите «вадян» с новой иконки.

MP3 импортируются через выбор файлов. Треки и обложки сохраняются в IndexedDB браузера и доступны без интернета после первого открытия/кэширования.

Для полноценной офлайн-работы PWA должен быть размещён по HTTPS (или на localhost).

## Бесплатный хостинг

Подойдут статические хостинги с HTTPS, например GitHub Pages. Никакого сервера для музыки не требуется: файлы пользователей остаются в браузере устройства.
